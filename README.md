# micro:bit Learning Platform

A team project for CI489 at UIUC, Spring 2026, supporting introductory programming and physical computing.

## Prototype preview

See Figma: https://www.figma.com/make/DnUTeW6aiX169ZkKPU0Ur3/Interactive-Learning-Platform?t=lTATRSdUCatb7Wbf-1

## Features

- Guided lessons and coding challenges.
- Block-based workspace and on-screen micro:bit simulator.
- Reflection questions and collaborative activities.
- Browser-local progress tracking.

## Design and Evaluation

The platform was informed by educator consultation, classroom observation, and a field test with 20 sixth-grade students.

**My role:** Technical Lead.

**Team:** Adhwita Gopi Selvan, Daniel Chen, Matthew Port Louis, and Xiaoxi Chen.

## Stack

React · TypeScript · Vite · Tailwind CSS

The frontend was developed through Figma Make.
